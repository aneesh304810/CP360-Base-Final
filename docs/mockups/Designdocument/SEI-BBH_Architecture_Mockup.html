Numbers are the component IDs in the design tracker. The eight Python items carrying a high-custom mark are the real build: validation, DQ, replay, recon, config. dbt is comparatively thin — five Stage 2 models, five Gold, two hard macros.

Blocked on a decision

  1. AD-1 Gold writes a Hub schema or PBDW/IMDS direct — blocks 16, 37, 60
  2. AD-2 Corrections bitemporal or in-place merge — blocks 17, 21, 31, 59
  3. AD-3 Apigee: decision or placeholder — blocks 11, 12
  4. AD-4 Intraday on batch or API lane — blocks 12, 20
  5. AD-5 Partial batch: halt-all or per-domain — blocks 18, 22
  6. AD-6 Reconciliation system of record — blocks 7, 30, 35

Build order follows from this: item 33, the config store, comes first — items 13, 18, 23 and 28 are all meant to be config-driven and will be hardcoded if it isn't there.
